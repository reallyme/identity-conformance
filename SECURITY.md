# Security policy

Do not open a public issue for a suspected vulnerability, leaked credential,
unredacted conformance result, or privacy-sensitive certification artifact.
Use GitHub's private vulnerability reporting feature for this repository.

Include only the minimum information required to reproduce the problem. Do not
include production credentials, private keys, personal data, or raw identity
protocol transcripts. ReallyMe will coordinate a safe disclosure after the
affected material has been contained and credentials have been rotated.
