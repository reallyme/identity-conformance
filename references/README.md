# Normative source references

These files record the standards used across ReallyMe identity repositories.
`normative-sources.lock.json` records each publication's official
URL, edition, byte length, and SHA-256 digest. Copyrighted standards are listed
but not copied into this repository.

Clause reviews separate the standard's requirements from ReallyMe design
choices and implementation evidence. A citation or parser test does not prove
complete product conformity.

`pin-policy.json` lists the releases and immutable references checked by the
weekly freshness workflow. It also names sources that need manual review.

The ETSI TS 119 472 series review is in `etsi-ts-119-472-series.md`. Its EU PID
legal alignment and current consolidated implementing-act baseline are in
`eu-pid-2026-alignment.md`.

The generated ETSI/EU requirement map is under `etsi-eaa-pid/`. It traces
requirements to source; it is not a test result. Files under
`taxonomy-advisory/` support manual analysis and are not release inputs or
product evidence.
