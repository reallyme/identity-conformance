## Clause findings and SSI evidence

| Clauses | Normative finding | SSI projection or validation evidence |
| --- | --- | --- |
| 5.1.2, 5.1.4, E.2 | URI fields use RFC 3986 syntax. Multilingual character strings carry lower-case RFC 5646 language tags and exclude the prohibited control and private-use characters. | `parse/scalars.rs` validates bounded URIs, language tags, and multilingual text. The derived parser tests cover malformed language tags. |
| 5.3.5, 5.3.5.2 | The scheme-operator address contains postal and electronic parts. The electronic part includes a mandatory email URI, mandatory website URI, and optional telephone URI. | `parse/project/address.rs` retains every localized URI and validates the required roles by URI scheme. This avoids discarding repeated localized website values seen in deployed lists. |
| 5.4.3, 5.4.3.2 | A TSP address has the same required postal/electronic shape and electronic roles as the scheme-operator address. | The shared typed address projection is used for both contexts and emits context-specific, non-sensitive errors. |
| 5.5.3 | A current service has one logical digital identity. A non-PKI service uses a URI; a PKI service may use the listed X.509 representations of the same public key. | The projection rejects mixed PKI/non-PKI identities and unsupported structured `Other` content. |
| 5.5.9.2.2.2 | `PolicySet` contains one or more certificate-policy Object Identifiers. | Policy identifiers are normalized from the schema's supported XAdES identifier forms to bounded dotted-decimal OIDs; arbitrary URI values fail closed. |
| 5.5.9.3 | `TakenOverBy` identifies the successor through a URI, TSP name, scheme-operator name, and scheme territory; a critical instance must be understood completely. | The parser validates all defined required children and rejects incomplete or unrecognized critical semantics. |
| 5.6.3 | A historical service identity reuses the service-identity representations subject to two additional constraints: it excludes certificates and includes at least `X509SKI`. | Historical projection rejects certificates, requires the SKI representation, and rejects URI-only history entries. Current non-PKI service identities remain available under clause 5.5.3. |
| B.0 | Unknown critical extensions cause rejection; unknown non-critical extensions may be ignored. | The bounded XML pre-scan and typed projection enforce this distinction without retaining unbounded extension trees. |
